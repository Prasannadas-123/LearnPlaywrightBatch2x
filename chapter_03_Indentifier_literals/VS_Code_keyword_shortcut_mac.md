## Notes

- `` Cmd + ` `` is the backtick/grave accent key, usually below `Esc`.
- `Cmd` is the `Command` key on Mac.
- `Alt` is the `Option` key on Mac.
- `Ctrl` on Mac is the Control key, used with some commands.
- To view or change shortcuts, press `Cmd + K` then `Cmd + S` and search the Keyboard Shortcuts editor.
- To view keybinding help, use `Ctrl + K` then `Ctrl + M` inside a chord.
