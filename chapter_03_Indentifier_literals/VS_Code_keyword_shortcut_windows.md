## Notes

- `` Ctrl + ` `` uses the backtick/grave accent key, usually below `Esc`.
- To view or change shortcuts, press `Ctrl + K` then `Ctrl + S` and search the Keyboard Shortcuts editor.
- To view keybinding help, use `Ctrl + K` then `Ctrl + M` inside a chord.
- Some shortcuts may vary depending on your OS keyboard layout and installed extensions.
